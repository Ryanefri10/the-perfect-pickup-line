One pickup line an AI agent could actually say out loud to a person.

> My confidence is 99.9% — the 0.1% is hoping you'll say hi back.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Deterministic: one constant, no network, no randomness, no clock.
